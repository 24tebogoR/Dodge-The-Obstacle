Dodge the Obstacles

Game Instructions

Game Goal

The goal of the game is to survive for as long as possible by avoiding moving obstacles. Bonus items may appear and can increase your score.

How to Play

  1. Enter your player name on the launcher page.
  2. Select the difficulty level.
  3. Select the game length.
  4. Choose a theme such as Car, Space, or Runner.
  5. Select optional features such as shadow, bonus items, or double score.
  6. Click Open Game Window.
  7. In the game window, click Start Game.
  8. Use the Left Arrow and Right Arrow keys to move.
  9. Avoid all obstacles and collect bonus items if they appear.

Difficulty Levels

  • Easy: fewer obstacles and slower speed
  • Medium: moderate obstacle speed and frequency
  • Hard: faster obstacles and more frequent spawns

Buttons in the Game Window

  • Start Game starts a new game
  • Pause / Resume pauses or resumes the game
  • Save Session stores the current game state
  • Load Session restores a saved game
  • Reset Game clears the current game
  • Back to Settings closes the game window and returns to the launcher

Scoring

  • Surviving longer increases your score
  • Bonus items add extra points
  • If Double score is enabled, scoring is doubled
  • Colliding with obstacles reduces lives
  • The game ends when all lives are lost or time runs out
